### Defect Record

- **ID:** BUG-001
- **Title:** Submitted Location is not saved to the database
- **Cause:** The INSERT statement omits the Location column, its placeholder and its `bind_param` value, so only FirstName, LastName and GovPosition are stored.
- **Impact:** Data is lost, and the user still sees a success message.
- **Suggested fix:** Add `Location` to the INSERT column list, add a fourth `?` placeholder, and bind four strings including `$Location`.
