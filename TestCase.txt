Defect record
ID: BUG-001
Title: Submitted Location is not saved to the database.
Affected field: main_corrupt_politicians.Location
Severity: Medium (data is lost, and the user still sees a success message)
Steps to reproduce: Enter a value in Location, click Send Wish Note, click Confirm & Send, then query the table.
Expected: The Location value is stored.
Actual: Location is NULL.
Cause: The INSERT statement leaves out the Location column and the matching placeholder and bind_param value, so only FirstName, LastName and GovPosition are inserted.
Suggested fix: Add Location to the INSERT column list, add a fourth ? placeholder, and bind four string values including $Location.
